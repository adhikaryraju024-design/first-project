# Mail Manager - Mobile & Desktop Bulk Email Campaign Dashboard

একটি শক্তিশালী, রেস্পন্সিভ ও আধুনিক **বাল্ক ইমেইল ক্যাম্পেইন ড্যাশবোর্ড** যা আপনার জিমেইল একাউন্ট ও ভিপিএস সার্ভারের (Docker) সাথে সরাসরি সংযুক্ত হয়ে ৫০+ প্রার্থীর কাছে হেডার ইমেজ ও ফরম্যাটেড নোটিশ সহ একসাথে ইমেইল পাঠাতে পারে।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

- 📱 **মোবাইল ও ডেস্কটপ ফ্রেন্ডলি ডিজাইন:** নিখুঁত ইউজার ইন্টারফেস (UI), যা মোবাইল ও পিসি যেকোনো স্ক্রিন থেকেই সহজে ব্যবহারযোগ্য।
- 👥 **৫০+ প্রাপক তালিকা হ্যান্ডলিং:** টেক্সট এরিয়ায় সরাসরি ইমেইল পেস্ট করা, CSV/TXT ফাইল আপলোড বা এক ক্লিকে ৫০ জনের স্যাম্পল লোড করার সুবিধা।
- 🖼️ **ইনলাইন হেডার ইমেজ ব্যানার (CID Attachment):**
  - নোটিশের শুরুতে যেকোনো ব্যানার/হেডার ছবি আপলোড (PNG, JPG, WebP)।
  - জিমেইলে ছবিটি সাধারণ লিংকের মতো ব্লক না হয়ে ইনলাইন হিসেবে গ্রাহকের ইনবক্সে সরাসরি প্রদর্শিত হয়।
- 👁️ **লাইভ প্রিভিউ (Live Preview Modal):** মেইল পাঠানোর আগেই মোবাইল বা কম্পিউটার ভিউতে দেখে নেওয়ার সুবিধা।
- ✉️ **টেস্ট ইমেইল সুবিধা:** ৫০ জনকে পাঠানোর আগে নিজের মেইলে ১টি টেস্ট মেইল পাঠিয়ে যাচাই করার ব্যবস্থা।
- 🛡️ **স্প্যাম ও রেট-লিমিট সুরক্ষা:** প্রতি মেইলের মাঝে ১.৫ - ২ সেকেন্ডের অটোমেটিক বিরতি, যাতে জিমেইল আপনার একাউন্ট ব্লক বা স্প্যাম হিসেবে চিহ্নিত না করে।
- 📊 **রিয়েল-টাইম প্রগ্রেস ও লাইভ লগ:** কতটি মেইল সফলভাবে ডেলিভার্ড হলো এবং কতটি বাউন্স/ব্যর্থ হলো তার লাইভ পরিসংখ্যান।
- 🐳 **ডকার রেডি (Docker Ready):** আপনার ভিপিএস সার্ভারে ডকার কম্পোজ দিয়ে মাত্র ১ কমান্ডে ডিপ্লয় করা সম্ভব।

## 🔑 জিমেইল অ্যাপ পাসওয়ার্ড (Google App Password) তৈরি করার নিয়ম

সাধারণ জিমেইল পাসওয়ার্ড দিয়ে গুগল সরাসরি থার্ড-পার্টি বা সার্ভার থেকে লগইন অনুমোদন করে না। এর জন্য গুগলের অফিসিয়াল ১৬ ডিজিটের **App Password** ব্যবহার করতে হয়:

1. আপনার গুগল একাউন্টে লগইন করে সিকিউরিটিতে যান: [myaccount.google.com/security](https://myaccount.google.com/security)
2. **2-Step Verification** (দ্বি-স্তর বিশিষ্ট যাচাইকরণ) চালু আছে কিনা নিশ্চিত করুন (চালু না থাকলে চালু করে নিন)।
3. এরপর সরাসরি অ্যাপ পাসওয়ার্ড পেজে যান: [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)
4. অ্যাপের নাম হিসেবে লিখুন (যেমন: `Mail Manager`) এবং **Create** এ ক্লিক করুন।
5. গুগল আপনাকে ১৬ অক্ষরের একটি পাসওয়ার্ড দেবে (যেমন: `abcd efgh ijkl mnop`)।
6. এই পাসওয়ার্ডটি কপি করে ড্যাশবোর্ডের সেটিংস আইকন (⚙️) এ গিয়ে পেস্ট করে দিন।

## 🐳 আপনার ভিপিএস সার্ভারে ডকার দিয়ে চালানোর উপায় (VPS Deployment)

আপনার ভিপিএস সার্ভারে যদি ডকার (`docker` এবং `docker compose`) ইনস্টল করা থাকে:

### ধাপ ১: রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/adhikaryraju024-design/first-project.git
cd first-project
```

### ধাপ ২: ডকার কন্টেইনার চালু করুন
```bash
docker compose up -d --build
```

### ধাপ ৩: ব্রাউজারে ওপেন করুন
আপনার ব্রাউজারে গিয়ে টাইপ করুন:
```
http://YOUR_VPS_IP:3000
```
*(যেখানে `YOUR_VPS_IP` হলো আপনার ভিপিএস সার্ভারের আসল আইপি এড্রেস)*

ব্যাস! আপনার ড্যাশবোর্ড প্রস্তুত।
